Adding it to your mail app

  1. GmailClick Copy signature, then go to Settings → See all settings → General → Signature, create a new one and paste. Save at the bottom of the page.
  2. Apple MailMail → Settings → Signatures, add a signature, untick Always match my default message font and paste. Close Settings so it saves.
  3. OutlookSettings → Accounts → Signatures, create a new one and paste. The new Outlook and Outlook on the web play the animation; classic Outlook for Windows shows the first frame.

The GIF loads from gjacko33.github.io/assets/signature/, so push this folder before pasting it anywhere. The card is recorded from signature/card.html; edit that page and re-record it to change the design.
